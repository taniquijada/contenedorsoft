# El problema del aislamiento

Para entender bien este tema, tenemos que partir de la idea de que un modelo de lenguaje no es lo mismo que el sistema informático donde se ejecuta. 

Un LLM puede analizar texto, escribir código, explicar documentos y hasta generar instrucciones para modificar un archivo. Pero eso no quiere decir que pueda abrir cualquier archivo de tu computadora, guardarlo, borrarlo o cambiarlo por su cuenta. La clave está en una diferencia que a veces se pasa por alto una cosa es generar una instrucción y otra muy distinta es ejecutarla.

## 1. ¿Qué significa que un LLM recibe texto y devuelve texto?

Un modelo de lenguaje es, en esencia, un componente que procesa una entrada y genera una salida. En una conversación típica, la entrada puede ser una pregunta y la salida, una respuesta escrita.
