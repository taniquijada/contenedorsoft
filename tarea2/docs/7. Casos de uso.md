# Casos de uso

## 1. Edición de repositorios completos sin subidas manuales


Con MCP, las herramientas de desarrollo actúan como Hosts de MCP conectados a un servidor de sistema de archivos (y a un servidor de Git) local. Este mecanismo le permite al modelo hacer tres cosas:

- **Explorar la arquitectura del proyecto.** Navegar dinámicamente por el árbol de carpetas mediante herramientas como `directory_tree` y `list_directory`.

- **Analizar el contexto completo.** Leer múltiples archivos, definiciones de clases y dependencias usando `read_multiple_files`.

- **Aplicar refactorizaciones profundas.** Realizar parches y ediciones precisas en varios archivos de forma coordinada con `edit_file`, sin que el usuario tenga que mover ni subir código a mano.

## 2. Herramientas actuales que utilizan MCP

**Google Antigravity.** Es un entorno de desarrollo integrado (IDE) y plataforma de agentes de IA diseñada por Google. Funciona como un MCP Host avanzado que permite a los desarrolladores conectar servidores MCP locales y remotos para auditar, probar y modificar repositorios enteros directamente en el entorno de trabajo.

**Cursor.** Un entorno de desarrollo (fork de VS Code) optimizado para flujos de trabajo con inteligencia artificial. Como Host de MCP, permite registrar servidores MCP personalizados (bases de datos, herramientas de terminal o sistemas de archivos) para que los modelos inspeccionen y editen el código de todo el espacio de trabajo.

**Claude Code / Claude Desktop.** Herramientas desarrolladas por Anthropic (CLI y aplicación de escritorio) que actúan como clientes y hosts MCP. Permiten ejecutar agentes en la terminal o en la interfaz gráfica que leen el repositorio local, ejecutan comandos y aplican cambios directamente en los archivos del disco.

## 3. Precisiones técnicas sobre plataformas y modelos

Para usar la terminología adecuada al describir el ecosistema de IA y MCP, conviene distinguir entre entornos de desarrollo y familias de modelos:

- **Google Antigravity sí es un entorno de desarrollo.** Es una plataforma / IDE completa que actúa como Host de MCP para orquestar herramientas y agentes.

- **Qwen es una familia de modelos, no una plataforma.** Qwen  es un gran modelo de lenguaje (LLM), similar a familias como GPT, Claude o Gemini. Un modelo por sí solo no es un entorno de desarrollo ni un servidor MCP: es el motor de razonamiento que se aloja dentro de una plataforma Host (como Antigravity, Cursor o VS Code) para interactuar con el protocolo MCP.
